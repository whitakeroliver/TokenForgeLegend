# TokenForgeLegend

TokenForgeLegend enables real-time, distributed data processing and dynamic token generation within a secure, decentralized system platform.

TokenForgeLegend is built to be simple and practical, focusing on doing one thing well.

**Why TokenForgeLegend?**

- TokenForgeLegend enables real-time, distributed data
- processing and dynamic token generation

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/TokenForgeLegend.git`
2. `cd TokenForgeLegend`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenForgeLegend, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
